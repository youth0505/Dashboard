# Dashboard 集合

根目录页面是 Dashboard 集合的首页和目录。

- 集合首页：[`index.html`](index.html)
- Formula 1 概念仪表板：[`f1-dashboard.html`](f1-dashboard.html)
- 维护说明：[`MAINTENANCE.md`](MAINTENANCE.md)
- Portfolio 入口：[Lingfei Zhu Portfolio](https://youth0505.github.io/Portfolio/)

F1 页面是静态概念预览，其中的筛选器、KPI、图表和表格数据均未连接实时数据源。新增仪表板时，请将其添加到集合首页，并链接到独立页面。

集合首页和 F1 页面均支持中英文切换，语言选择会保存在浏览器中。
